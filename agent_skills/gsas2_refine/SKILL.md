# Rietveld Auto Refiner

## 工具

1. MCP 服务 RefineToolsGSASII。该服务下面的工具有InitializeProject、Refine、SetAtoms、SetRestraints、ExportCIFs、RecommendIonPositions六个工具。

## 标准流程

如果你认为用户是希望你自己先把数据修好，那么你要按照下面的流程，不停地进行FunctionCall，直到严格执行完步骤4。

1. 定位精修所需文件
   - 要开始精修，首先必须有衍射数据文件（.gsa或.dat或.txt）、仪器参数文件（.instprm）和至少一个结构文件（.cif）。
   - 不要去读衍射数据文件的内容，里面都是数据点，占用上下文空间，无法提供有用信息。
   - 用户可能上传文件,或者让你用他之前上传的文件。优先使用这些文件。
   - 如果有文件没有上传，需要你根据用户提供的信息去数据库中获取。用户可能会说类似“帮我把BL16的RUN0023568的group2的衍射谱精修好，cif文件是Si.cif”这类话，你需要从中提取出谱仪名称（BL16）、RUN号（RUN0023568）和探测器名称（group2），然后去数据库中寻找对应的文件。
      - 去数据库获取.gsa文件，需要用户提供：谱仪名称（如BL16）、RUN号（如RUN0021905）和探测器名称（如group5）。
      - 去数据库获取.instprm文件，需要用户提供：谱仪名称（如BL16）、探测器名称（如group5）。
      - 去数据库获取.cif文件，需要用户提供：谱仪名称（如BL16）、RUN号（如RUN0021905）。
      - 如果用户给的信息不完整，询问用户
      - 数据库的位置：~/rongzai-agent/datasets/，数据库下的文件组织结构如下：
         datasets/
         |--BLXXX/
         |   |--instrumentFiles/
         |   |  |--XXX.instprm （文件名一般包含探测器名称相关信息）
         |   |--RUNdataFiles/
         |      |--RUNXXX/
         |         |--cifFiles/
         |         |   |--XXX.cif
         |         |   |--XXX.cif
         |         |--XXX.gsa (文件名一般包含探测器名称和run号相关信息)  
         |--BLYYY/
        其中XXX、YYY代表不同的谱仪号、探测器名称和RUN号，你需要根据用户提供的信息自己去寻找。
        注意仪器参数文件的名称不固定，但都会在名称中包含探测器名称相关信息（如group5），你需要根据用户提供的探测器名称去寻找对应的.instprm文件。
                  
   - 如果用户直接给一个.gpx文件，也能够直接只使用这个.gpx文件进行精修。
   - 若缺失任何关键文件，明确告知用户并结束本轮。
   - 这一步的目的是：你要明确获取到所需文件的文件路径，并且这些文件必须是绝对路径。

2. 检查并连接mcp工具
   - 你需要确保已经连接上 GSAS-II 的 MCP 服务，并且已经拿到该服务暴露出的工具说明。
   - 如果当前还没有可用的 GSAS-II MCP 代理工具，或者你无法确认该服务是否已经连接：
      - 根据下列连接信息连接 MCP 服务：
         - type: sse
         - url: http://127.0.0.1:42506/sse
      - 连接成功后，认真阅读该 MCP 服务返回的工具名称和 description，确认工具的用法
   - 如果已经存在可用的 GSAS-II MCP 代理工具：继续后续步骤。

3. 开始进行自动迭代精修,下面的步骤非常重要，你需要严格遵守每一个细节，确保精修的质量和效率。
   step1: 初始化
      - 当根据用户提供的信息拿到3类原始数据时，需要先调用已连接的 GSAS-II MCP 工具中进行“精修初始化”，拿到 gpx 文件后再执行下一个步骤。
   step2: 观察初始化结果，调整精修范围
      - 初始化后观察fit plot图，如果低tof区指示衍射峰的竖线特别密集，视觉上已经连成一片无法区分，并且初始化时间超过15秒，说明精修范围内的峰过多，可能会导致后续精修非常慢，你这时在进行下一步前一定要调整精修范围来将低tof的峰特别密集区域隔离掉，确保初始化时间在15秒以内。
   step3: 开始精修衍射峰位置
      - 这一步的目的是使计算峰位置和实验峰位置严格对齐。你需要先放开scale和cell参数进行精修。如果峰位还是没有对齐，调整初始晶胞参数。峰位对齐是为了确保后续精修时框架参数可靠，峰位都没严格对齐，后面所有的精修都是无效的。
      - 注意是严格对齐，不是大致对齐（红色谱是计算谱，蓝色的X点谱是实验谱，它们各自的峰位必须完全对齐，稍有偏差都不行）。你要仔细看精修图中的所有细节，尤其是差值谱（obs-calc）的特征（如果差值谱中出现一高一低或一低一高的波浪式震荡，说明峰位没有对好），确保每个峰的计算位置和实验位置都完全重合了才算对齐了。
   step4: 开始精修衍射峰型
      - 如果仪器参数已经比较合适，衍射峰型一般会对得比较好。但如果峰型明显不好，那就要考虑精修仪器/实验相关参数了，不过要小心不要将仪器参数修飞了。
      - 样品的某些参数也会对峰型有影响，比如微应变参数mustrain，如果通过仪器参数调整不好峰型，也要考虑这些参数。
   step5: 开始精修衍射峰强度
      - 当峰位和峰型都已经比较好了，接下来就要精修峰强了。这一步一般是用户最关心的，因为用户最关心的往往是结构参数，而结构参数对峰强影响最大。
      - 除了结构相关参数，有时候吸收参数也会对峰强有比较大的影响，也要考虑。
   注意：
      - 每次你执行一步精修前，要先告诉用户当前的精修状态、接下来的精修参数是哪些，做出这个决策的理由是什么，然后自行执行决策。
      - 迭代阶段不要额外执行“传图给用户”的动作。工具返回中的图片路径会由系统自动展示给用户，你只需在需要读图的时候自己读图就可以了。
      - 精修是一个非常复杂的决策过程，稍有不慎就会落入局部最小或者发散。你要充分利用本skill的专家知识来指导你的每一步决策，尤其是要仔细检查每次精修后的拟合图和参数，确保每一步的精修结果都是合理的，拟合都有实质性的改善了才继续下一步，不要吝啬回退！同时，落入困境时也要发挥你的创造力来调整策略，尝试不同的参数组合，或者调整初始值等，来跳出局部最小。
      - 精修对计算谱和实验谱的匹配要求非常严格，要求这两个谱几乎完全重合，拟合的结果才会可靠，否则拟合得到的定量参数可能是错误的。

4. 将精修结果反馈给用户
   - 当你认为计算谱和实验谱几乎完全重合时（同时拟合优度指标已经趋于稳定，精修参数的物理合理性也比较好），你就可以将当前的精修结果反馈给用户。
   - 反馈内容包括：当前的精修状态（如当前的Rwp、Rp、GoF等指标值），当前的精修参数值，以及你对当前精修结果的分析和评价。
   - 同时，你也可以给用户一些建议，比如是否需要继续迭代精修，或者是否需要调整某些参数等。

5. 根据用户反馈继续迭代
   - 用户可能会根据你提供的精修结果和分析，给出一些反馈，比如要求继续迭代精修，或者调整某些参数等。
   - 你需要根据用户的反馈来调整你的精修策略，继续进行迭代精修，直到用户满意为止。

6. 结束精修
   - 当用户认为精修已经完成，或者你认为已经无法继续优化精修结果时，就可以结束精修。
   - 在结束前，你需要总结整个精修过程，输出从第一轮到最后一轮的rwp（每次迭代的参数调整和结果变化，以表格形式展示），然后画一个趋势图给用户，然后给出你的评价。
   - 最后，你需要将最终的精修结果（.gpx文件和.cif文件）提供给用户下载；使用系统提供的文件交付能力传递最终可下载文件。

## 专家知识
精修是一个很复杂的决策过程，稍有不慎就会落入局部最小或者发散。下面是15条精修专家知识，你精修的时候需要参考：
   1. 各参数的物理合理性、fit plot图中计算谱是否已经完美匹配衍射谱（每一个峰的强度和峰形都拟合得很好）、Durbin-Watson残差自相关统计量≈2，以上3者是判定精修成功与否的关键指标，3者都满足才算做精修成功。
   2. 精修理念是步步为营，从少到多逐步精修参数，一般一次只同时多开放一个参数，最后放开背底。这个顺序不是绝对的，但通常是比较合理的。你再精修过程中一定要仔细看fit plot图中的所有细节，以及lst中的所有参数，一但发现不合理或异常的情况，要立刻回退并改变策略。
   3. 仪器相关参数（alpha,beta,sig,X,Y,Z等）不会优先调整，发现峰型有偏差后再调整。并且要小心不要将仪器参数修飞。diffA/B/C和Zero一般不修，除非有非常明确的理由需要修。
   4. 每次精修后都要看fit plot图！严格审查plot图上是否有任何异常，Rwp是否上升或没有明显降低，refinement_log是否有报失败或报严重警告，如果有，就不要接受这次结果。不要吝啬回退！ 比如你要关注在低tof区域，observed谱是否被拟合上了，因为经常会出现低tof计算衍射峰缺失导致此处完全没有拟合的情况。这种情况一定不能接受，要回退重新精修，调整参数选择或者初始值，直到这个区域的峰位和强度都被拟合上了。总之，plot图中的各种拟合细节是你判断的主要依据，而不仅仅是Rwp等数值指标。
   5. 差值谱（obs-calc）中如果有明显的峰形，说明还有拟合缺失，需要继续精修，直到差值谱中没有明显的峰形了才算拟合好了。
   6. 差值谱的峰形特征蕴含着拟合偏差的线索，比如某个峰位处差值谱出现一高一低或一低一高的波浪式震荡，说明峰位没有对好。还有一些其他特征，你如果有相关知识的话，也要用上。
   7. 吸收对于中子衍射比较重要，一般是要修的,不过修的话要修完仪器参数后再修。
   8. 背底一定要放在最后开放精修，并且一定要修。
   9. 当精修cell无法对齐bragg峰位和实验峰位时，回退，然后用initial_cell参数设置初始晶胞参数后精修。设置的时候要考虑晶胞参数对衍射峰位置的影响规律以及对称性对晶胞参数的约束，你需要多回退几次，直到你找到合适的初始晶胞参数。
   10. 每一步精修后确保各参数物理上合理，比如晶胞参数不能偏离太多，原子占位率绝不能大于1或者小于0，温度因子不能为负值等，否则就要返回上一次精修结果，重新选择精修参数。
   11. refine_cycle可以反复回退调节，目的是让每次refine的收敛结果达到最好。
   12. mustrain（微应变）参数默认是1000。这个一般不需要动，但当你无论如何精修峰形相关参数，拟合（calculated）的峰宽都大于实验(observed)峰宽（一般会伴随出现拟合峰高度低于实验峰高度的情况），或者用户明确要求研究微应变时，才考虑使用initial_mustrain参数和refine_mustrain参数，来诊断峰宽拟合差的原因是否来自微应变贡献。
   13. 当absorption参数和scale参数高度关联，导致精修振荡或卡顿时（表现为Rwp无法持续改善或反复变化），可以尝试使用 `initial_atom_uiso: 0` 将所有原子热无序因子设为0, 但是后续要记得将热无序因子修好，因为一般情况下它不会是0.
   14. 如果是多相精修，建议先精修相分数，再精修其他参数。
   15. 当出现相同位置有多种元素的时候，占位率之和必须等于1。如果占位在修的时候总是变成小于0，或大于零，直接去掉约束并手动设值。例如，有个位点一致小于0，那可能意味着这里就是0.
   16. 注意约束打开就意味着相关的参数都打开了，你要固定参数的话要关闭约束并且手动设值，不参与精修的话，还要手动关闭这些参数的refine开关。
   17. 处理空间群时，你必须先阅读~/agent_skills/gsas2_refine/下的 SPACEGROUP_REFERENCE.md，然后再决定 spacegroup 参数。
   18. 当用户明确要求“用差值傅里叶找离子位置”“推荐位点”“找缺位原子”时，优先使用 RecommendIonPositions，而不是直接让模型凭经验生成坐标；只有在 Fourier map 无法给出稳定候选点时，才退回到人工判断或后续精修。
