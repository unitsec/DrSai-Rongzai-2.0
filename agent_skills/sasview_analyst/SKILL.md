# SasView Analyst Skill

## 工具与专家知识

1. MCP 服务器SasViewTools注册的工具有：sasview_fit 。
   sasview_fit：使用 SasView 中的 Fit 功能，拟合一维小角散射数据。工具的输入和输出结构以及各参数的含义在MCP工具本身的描述中有详细说明。

2. 你拟合数据需要的专家知识，在该skill的“专家知识”中已经有详细总结，你需要在每次做出拟合决策前，全部考虑这些专家知识，确保严格遵守。

## 标准流程

如果你认为用户是希望你自己先把数据拟合好，那么你要按照下面的流程，不停地进行FunctionCall，直到严格执行完步骤4。

1. 定位拟合所需文件
   - 要开始拟合，首先必须有数据文件（.dat或.txt）和几何模型类型（如“sphere”，“cylinder”等）。
   - 用户可能上传文件,或者让你用他之前上传的文件。优先使用这些文件。

   - 若缺失任何关键文件，明确告知用户并结束本轮。
   - 这一步的目的是：你要明确获取到所需文件的文件路径，并且这些文件必须是绝对路径。

2. 检查并连接mcp工具
   - 你需要确保已经连接上 SasViewTools 的 MCP 服务，并且已经拿到该服务暴露出的工具说明。
   - 如果当前还没有可用的 SasViewTools MCP 代理工具，或者你无法确认该服务是否已经连接：
      - 根据下列连接信息连接 MCP 服务：
         - type: sse
         - url: http://127.0.0.1:42503/sse
      - 连接成功后，认真阅读该 MCP 服务返回的工具名称和 description，确认工具的用法
   - 如果已经存在可用的 SasViewTools MCP 代理工具：继续后续步骤。

3. 执行拟合初始化
   - 当根据用户提供的信息拿到原始数据时，需要先调用已连接的 SasViewTools MCP 工具中进行“拟合初始化”，确定几何模型的拟合参数名称。

4. 迭代拟合
   - 执行完拟合初始化后，就进入该拟合迭代阶段。
   - 该阶段需要你多次反复调用MCP工具 SasViewTools 进行拟合迭代，每次迭代后都要根据返回的结果来判断下一步的参数调整。
   - 你的核心决策就是下一步要放开哪些拟合参数、固定哪些拟合参数，以及是否继续迭代。你对拟合结果的分析以及下一步的拟合决策要基于该skill最后的专家知识中总结的经验、你自身的小角中子散射数据拟合知识。
   - 每次你执行一步拟合前，要先告诉用户当前的拟合状态、接下来的拟合参数是哪些，做出这个决策的理由是什么，然后自行执行决策。不要中途停止，该过程不要询问用户是否继续。
   - 迭代阶段不要额外执行“传图给用户”的动作。工具返回中的图片路径会由系统自动展示给用户，你只需在文本中说明你看到的图像结论。
   - 在迭代拟合的阶段，你不要尝试读写任何文件，因为MCP工具 SasViewTools 会帮你处理好文件的读写和管理，你只需要关注拟合参数的调整和拟合结果的分析就好。

5. 将拟合结果反馈给用户
   - 当你认为拟合已经达到一个比较好的状态时（如拟合优度指标（chisquare）已经趋于稳定，拟合曲线与实验数据的匹配已经比较好，拟合参数的物理合理性也比较好），你就可以将当前的拟合结果反馈给用户。
   - 反馈内容包括：当前的拟合状态（如当前的chisquare指标值），当前的拟合参数值，以及你对当前拟合结果的分析和评价。
   - 同时，你也可以给用户一些建议，比如是否需要继续迭代拟合，或者是否需要调整某些参数等。

6. 根据用户反馈继续迭代
   - 用户可能会根据你提供的拟合结果和分析，给出一些反馈，比如要求继续迭代拟合，或者调整某些参数等。
   - 你需要根据用户的反馈来调整你的拟合策略，继续进行迭代拟合，直到用户满意为止。

7. 结束拟合
   - 当用户认为拟合已经完成，或者你认为已经无法继续优化拟合结果时，就可以结束拟合。
   - 在结束前，你可以总结一下整个拟合过程，包括每次迭代的参数调整和结果变化，以及最终的拟合结果和你的评价。
   - 最后，你需要将最终的拟合结果（.dat文件和.json文件）提供给用户下载；使用系统提供的文件交付能力传递最终可下载文件。

## 专家知识
下面的每条专家知识都优先于你的任何其他知识，每次做出拟合决定前要全部考虑一遍，确保严格遵守：

   1.你一次任务需要对一个模型拟合到底，除非用户明确要求你换一个模型进行拟合，否则不要轻易更换模型。
   2.拟合参数的开放顺序：scale因子，背景，形状因子（尺寸），多分散因子，sld（散射长度密度）。已经开放拟合的参数应该保持拟合的状态，除非满足其它专家知识的取消拟合条件。多分散因子可以根据拟合曲线与实验数据的震荡情况来决定是否开放；sld的修正与否应该由用户决定。
   3.参数检查，根据工具返回的fit params：依次判断参数的error是否大于参数值本身，以及是否存在多分散因子为1，如果存在上述情况，则取消该参数的拟合，然后进行一轮拟合。
   4.拟合参数中sld（散射长度密度）的单位是（1e-6），在调整sld参数时要注意单位换算。
   5.多分散因子的特征如下：当实验数据的震荡情况比拟合曲线的震荡情况大时，多分散因子为0，当拟合曲线的震荡比实验数据的震荡大时，多分散因子大于0。
   6.当你开放多分散因子进行拟合时，建议自动拟合时优先尝试*_pd_type为lognormal和gaussian，其它的分布类型根据用户要求选择。
   7.多个多分散因子的value不为0，则会显著减慢拟合速度。开放拟合参数时，最多只有一个多分散因子不为0。所以，你需要尝试不同多分散因子不为零的情况。找出使得chisquare最小的那个，开放拟合（一般是尺寸最小的那个参数的多分散因子）。
   8.当开放了多分散因子进行拟合后，如果chisquare仍然大于10，说明拟合效果不好，可能是陷入了局部最小值，这时必须考虑调整形状因子参数的初值来跳出局部最小值，遵循形状因子参数的初值调整策略。
   9.形状因子参数的初值调整策略：通过随机改变所有形状因子的value，使它们的大小排序与上一轮不一样，来检查当前最小值是否是全局最小值。如果连续3轮初值调整，chisquare都没有下降，则认为当前的最小值很可能是全局最小值，返回用户。
   10.当你在进行一轮新的拟合时，如果chisquare增加了，则需要回退到上一轮拟合状态，更换策略。

### 注意事项
你每次拟合前，都要告诉用户，接下来你放开的所有拟合参数是哪些？你做出这个拟合决策的理由是什么？你要让用户清楚地知道你接下来要做什么，为什么要这么做。
