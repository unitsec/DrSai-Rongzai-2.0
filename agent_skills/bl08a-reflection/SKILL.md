# BL08A 中子反射处理

1. 获取用户提供的 RUN 编号列表。必须包含且仅包含一个直通 RUN，并包含至少一个反射 RUN。工具会根据元数据 Rz 自动分类，不要猜测或编造 RUN 编号。
2. 连接 MCP 服务，type 为 sse，url 为 http://127.0.0.1:42520/sse。
3. 阅读服务返回的工具说明和参数格式，调用 process_neutron_reflection，传入 runs 字符串列表。
4. 根据实际返回结果报告成功或失败，以及结果所在的服务器路径。不要把服务器路径描述成用户可以直接下载的链接。
5. 工具共用管理员配置的输出目录，重复处理可能覆盖同名结果。目前尚未实现用户、会话输出隔离。
6. 该工具执行反射数据规约，不执行反射模型拟合。返回 success 只表示流程完成，不代表数据质量已验证。
