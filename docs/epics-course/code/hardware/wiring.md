# 接线与采购说明（第 7 章）

> **动手前先读完"安全底线"。** 这个实验台只做低压直流，不碰市电。

## 二、安全底线（不可跳过）

1. **只用低压直流（5V / 12V）**。不要用 220V 市电，即使继电器标称可以。
2. **不要用大功率加热器件**。本课程用"LED 当加热器"，功率不到 1 W，
   足够把一颗贴着的 DS18B20 加热好几度。
3. **LED 必须串限流电阻**（220Ω~1kΩ）。直接接 3.3V 会瞬间烧掉。
4. **舵机/电机用独立 5V 电源**，并且 **GND 一定要和开发板共地**。
   只用 USB 供电时，舵机一堵转，开发板会复位（这是新手最常见的"神秘重启"）。
5. **改线前先拔 USB**。带电插拔电机线容易击穿驱动芯片。
6. **杜邦线不要拉到桌面边缘以外**，避免拽倒设备。
7. 所有外露的导体不超过 5V，所以**没有触电风险**，但要小心**发热**和**短路冒烟**。

## 三、接线表（默认引脚，与固件一致）

| 功能 | 引脚 | 接线 |
|---|---|---|
| AI0 电位器 | GPIO34 | 电位器两端→3V3 与 GND；中间脚→GPIO34 |
| AI1 光敏 | GPIO35 | 3V3→光敏→GPIO35→10kΩ→GND（分压） |
| AI2 温度 | GPIO32 | 3V3→NTC/热敏→GPIO32→10kΩ→GND（有 DS18B20 时用 DS18B20） |
| DO0 LED | GPIO2 | GPIO2→220Ω→LED 长脚；LED 短脚→GND |
| 舵机信号 | GPIO13 | 舵机橙线→GPIO13；红线→5V（独立电源）；棕线→GND（共地） |
| 按键 | GPIO0 | 按键一端→GPIO0，另一端→GND（用内部上拉） |
| DS18B20 | GPIO4 | 数据→GPIO4；数据与 3V3 之间接 4.7kΩ 上拉；另两脚→3V3/GND |
| 步进电机 | GPIO18/19/21/22 | ULN2003 的 IN1..IN4；驱动板电源 5V，共地 |

> ESP32 的 ADC 引脚注意：`GPIO34/35/32/33/36/39` 是**只输入**引脚，
> 不要拿来当输出；`GPIO0/2/12/15` 是启动模式引脚，外接电路可能影响启动
> （所以 LED 放在 GPIO2 时，**上电瞬间可能闪一下**，属正常）。

## 四、分步接线验证（每步都验证，不要一次全接）

| 步骤 | 接线 | 验证方法 | 期望结果 |
|---|---|---|---|
| 1 | 只插 USB | 串口能看到 `READY ...` | 固件活着 |
| 2 | LED + 电阻 | `DO 0 1` / `DO 0 0` | 灯亮/灭 |
| 3 | 电位器 | `AI 0`，边转边看 | 0~4095 变化，且两端不是恰好 0/4095（正常） |
| 4 | 光敏电阻 | 用手遮光，`AI 1` | 读数明显变化 |
| 5 | 舵机（先用独立电源） | `SERVO 0` / `SERVO 180` | 转动到位，开发板不复位 |
| 6 | DS18B20 | 读温度，用手捏住探头 | 温度上升到接近体温 |
| 7 | 步进电机 | 走 100 步 | 平稳转动、不丢步 |

**每次只加一个器件**：出问题时你才知道是谁的问题。
这就是"逐级隔离"，也是硬件调试唯一有效的方法。

## 五、常见硬件故障速查

| 现象 | 最可能的原因 | 检查方法 |
|---|---|---|
| 灯不亮 | 极性反 / 没串电阻 / 引脚写错 | 换 LED 试；万用表量 GPIO 电平 |
| ADC 读数一直 0 或 4095 | 接了只输出引脚 / 分压接错 / 引脚悬空 | 量中间点对地电压，应随旋钮变化 |
| 读数抖动厉害 | 线太长、没有共地、电源噪声 | 缩短线、加 0.1µF 电容、换 ADS1115 |
| 开发板随机重启 | 舵机/电机抢电流 | 电机独立供电 + 共地 + 加大电容 |
| 舵机抖动或嗡嗡响 | 电源电流不足 / PWM 频率不对 | 换 2A 电源；确认 50 Hz |
| DS18B20 读到 85.0 | 上拉缺失或接线松 | 检查 4.7kΩ 上拉 |
| 串口打不出字 | 波特率不对（应 115200）/ 选错串口 / 线只充电不传数据 | 换线！很多 USB 线只有电源线 |
| 一插上就被看门狗复位 | 上位机没及时发心跳 | 正常；桥每 0.1 s 轮询一次就不会触发 |

## 六、从"验证板子"到"接进 EPICS"的顺序（务必按这个顺序）

```
① 串口终端手动敲命令  →  证明固件和接线都对
② python c07_pv_bridge.py --sim   →  证明软件链路（PV 层）都对
③ python c07_pv_bridge.py --port /dev/ttyUSB0  →  两者合体
④ caget / caput 验证每个 PV
⑤ 再跑第 8 章的智能体流程
```

**跳过①或②的人，最后一定会被困在"到底是硬件问题还是软件问题"里。**
