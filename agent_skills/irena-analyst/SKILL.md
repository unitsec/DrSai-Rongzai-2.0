# Irena Analyst Skill

## 工具与专家知识

1. MCP 服务器IrenaTools注册的工具有：irena_size_distribution 。
   irena_size_distribution：使用 irena 中的尺寸分布计算工具，拟合一维小角散射数据，得到尺寸分布结果。工具的输入和输出结构以及各参数的含义在MCP工具本身的描述中有详细说明。

2. 你拟合数据需要的专家知识，在该skill的“专家知识”中已经有详细总结，你需要在每次做出拟合决策前，全部考虑这些专家知识，确保严格遵守。

## 标准流程

如果你认为用户是希望你自己先把数据拟合好，那么你要按照下面的流程，不停地进行FunctionCall，直到严格执行完步骤4。

1. 定位拟合所需文件
   - 要开始拟合，首先必须有数据文件（.dat或.txt）。
   - 用户可能上传文件,或者让你用他之前上传的文件。优先使用这些文件。

   - 若缺失任何关键文件，明确告知用户并结束本轮。
   - 这一步的目的是：你要明确获取到所需文件的文件路径，并且这些文件必须是绝对路径。

2. 检查并连接mcp工具
   - 你需要确保已经连接上 IrenaTools 的 MCP 服务，并且已经拿到该服务暴露出的工具说明。
   - 如果当前还没有可用的 IrenaTools MCP 代理工具，或者你无法确认该服务是否已经连接：
      - 根据下列连接信息连接 MCP 服务：
         - type: sse
         - url: http://127.0.0.1:42506/sse
      - 连接成功后，认真阅读该 MCP 服务返回的工具名称和 description，确认工具的用法
   - 如果已经存在可用的 IrenaTools MCP 代理工具：继续后续步骤。

3. 执行拟合初始化
   - 当根据用户提供的信息拿到原始数据时，需要先调用已连接的 IrenaTools MCP 工具中进行“拟合初始化”，生成初始化文件。

4. 迭代拟合
   - 执行完拟合初始化后，就进入拟合迭代阶段。
   - 该阶段需要你多次反复调用MCP工具 IrenaTools 进行拟合迭代，每次迭代后都要根据返回的结果来判断下一步的参数调整。
   - 你的核心决策就是下一步要放开哪些拟合参数、固定哪些拟合参数，以及是否继续迭代。你对拟合结果的分析以及下一步的拟合决策要基于该skill最后的专家知识中总结的经验、你自身的小角中子散射数据拟合知识。
   - 每次你执行一步拟合前，要先告诉用户当前的拟合状态、接下来的拟合参数是哪些，做出这个决策的理由是什么，然后自行执行决策。不要中途停止，该过程不要询问用户是否继续。
   - 迭代阶段不要额外执行“传图给用户”的动作。工具返回中的图片路径会由系统自动展示给用户，你只需在文本中说明你看到的图像结论。
   - 在迭代拟合的阶段，你不要尝试读写任何文件，因为MCP工具 IrenaTools 会帮你处理好文件的读写和管理，你只需要关注拟合参数的调整和拟合结果的分析就好。

5. 将拟合结果反馈给用户
   - 当你认为拟合结果已经达到一个比较好的状态时，你就可以将当前的拟合结果反馈给用户。
   - 反馈内容包括：当前的拟合状态（如当前的chisquare指标值），当前的拟合参数值，以及你对当前拟合结果的分析和评价。
   - 同时，你也可以给用户一些建议，比如是否需要继续迭代拟合，或者是否需要调整某些参数等。

6. 根据用户反馈继续迭代
   - 用户可能会根据你提供的拟合结果和分析，给出一些反馈，比如要求继续迭代拟合，或者调整某些参数等。
   - 你需要根据用户的反馈来调整你的拟合策略，继续进行迭代拟合，直到用户满意为止。

7. 结束拟合
   - 当用户认为拟合已经完成，或者你认为已经无法继续优化拟合结果时，就可以结束拟合。
   - 在结束前，你可以总结一下整个拟合过程，包括每次迭代的参数调整和结果变化，以及最终的拟合结果和你的评价。
   - 最后，你需要将最终的拟合结果（.dat文件和.json文件）提供给用户下载；使用系统提供的文件交付能力传递最终可下载文件。

## 专家知识
下面的每条专家知识都优先于你的任何其他知识，每次做出拟合决定前要全部考虑一遍，确保严格遵守：

   1.以下所有对参数的调整决策，都要基于拟合结果中的图片进行分析，依次做出判断。需要判断的情况如下：
      - 实验曲线（Data）有两种明显的背底特征：在低q区域是否出现显著的幂律下降，和在高q区域是否出现平坦的背景。
      - 第一步：判断高q区域，如果存在平坦背景，你需要调整平坦背景的范围，并进行平坦背景的拟合，直到背景曲线不高于实验曲线，才考虑其它参数的调整。
      - 第二步：判断低q区域是否存在幂律背景，如果存在幂律背景，你需要首先调整幂律背景的范围，开放背景的拟合。幂律背景的拟合有时可能会不太稳定，如果你发现幂律背景的拟合结果不太合理（比如背景曲线远高于实验曲线），你需要考虑固定幂律背景的斜率的拟合方式，并且缩短幂律背景的范围参数来避免将实验数据视为背景。如果仍然不能很好的降低幂律背景的贡献，你需要考虑暂时放弃幂律背景的拟合。
      - 幂律背景范围的最小值应该在实验数据的最小q值附近，否则极容易导致背景曲线高于实验曲线。
   2.n_points一般采用默认值即可，不改变半径分布点数，除非用户要求。
   3.你对参数做出调整决策一定是依次调整，不要一次改多个不关联的参数。每次调整参数后，你都要进行一次拟合迭代，观察拟合结果的变化，再决定下一组参数的调整。
   4.该方法结果的优劣有以下几点：chisquare指标较小，背景曲线绝对不能高于实验曲线，拟合曲线与实验数据的匹配良好，尺寸分布曲线有合理的形状（比如多峰，且峰的位置和宽度在合理范围内）。

### 注意事项
你每次拟合前，都要告诉用户，接下来你放开的所有拟合参数是哪些？你做出这个拟合决策的理由是什么？你要让用户清楚地知道你接下来要做什么，为什么要这么做。
