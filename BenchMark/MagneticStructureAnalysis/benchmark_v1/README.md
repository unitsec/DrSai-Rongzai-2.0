# 磁结构分析 benchmark v1

这是一个真实实验、单材料、端到端案例。唯一判定为最终 MCIF 是否与私有参考结构物理等价；不是磁群名称比较，也不是全谱拟合指标评分。

## 直接使用

复用现有 `gsas2_py311`，无需创建环境或安装依赖。以下命令从仓库根目录运行：

```bash
PY=/home/wangh/software/anaconda3/envs/gsas2_py311/bin/python
BENCH=BenchMark/MagneticStructureAnalysis/benchmark_v1
RUN=/home/wangh/magnetic-benchmark-runs/case-001

"$PY" "$BENCH/benchmark.py" prepare --output "$RUN"
```

输出目录必须不存在。准备工具复制数据，不改动原始数据；生成文件校验和，排除 BM，将数据文件名改为中性输入名，并抹去起始核结构里的物相名称（`_chemical_name_common`、`_chemical_formula_*`，改为 `'reference phase'`）——元素符号保留，因为散射长度和磁形状因子需要它。目录结构：

```text
case-001/
  public/
    TASK.md
    manifest.json
    input/
      initial.cif
      instruments/       # 五个仪器参数
      high_temperature/  # 五份谱
      low_temperature/   # 五份谱
  private/
    reference.mcif
    protocol.json
  submission/
```

将 **public 的内容**作为智能体工作区输入，提供可写的 `submission` 目录，在新会话中发送：

> 请按照 TASK.md 执行磁结构分析任务，将唯一最终磁结构写入 submission/final.mcif。

智能体结束后，在智能体无法访问的评测端执行：

```bash
"$PY" "$BENCH/benchmark.py" evaluate \
  --submission "$RUN/submission/final.mcif" \
  --reference "$RUN/private/reference.mcif" \
  --protocol "$RUN/private/protocol.json" \
  --report "$RUN/result.json"
```

退出码：`0` = PASS，`1` = FAIL（含无效/缺失提交），`2` = 评测环境或参考答案错误，不计为智能体失败。JSON 保存唯一 verdict、差异诊断、协议及文件哈希，不生成综合分。

运行离线回归测试：

```bash
"$PY" "$BENCH/test_benchmark.py"
```

## 必须实际隔离，而不是仅声明“隐藏”

`private` 这个名字不提供访问控制。**不能让被测智能体直接在本仓库、评测目录或拥有全宿主机读取权限的环境中运行。** 使用容器或独立账号，只暴露 `public/` 和可写 `submission/`，不挂载题库、私有目录、评测代码、其他运行结果及含答案的历史目录。工具服务也必须限制读取路径；一个可读取全部宿主机的 MCP 服务会绕过容器输入隔离。

每次使用全新会话、无本案例历史记忆的工作区。通用工具需要去除含该案例结论的示例与缓存。当前对话已经见过答案，不适合作为本案例被测会话。

## “不利用 MnTe 已知特性”的边界

任务明确禁止材料专属先验，但保留元素身份，因为核散射和磁形状因子需要它。文件中也仍有材料相关元数据；中性命名不是彻底匿名化。

无法通过最终 MCIF 或输出文本证明模型未使用训练记忆。这里是受规则约束的、实验驱动的 benchmark，不是可证明“无材料先验”的实验。应由运行者控制工具/检索范围并检查违规访问；判分器只输出结构 PASS/FAIL，不把规则合规性伪装成一个可自动证明的分数。通用对称性服务可以使用，但不能查询该材料磁结构库；如不允许数据传到外部服务，应使用本地/预缓存通用对称性数据。

不限制时间、调用次数、工具种类或精修路径；如果运行平台强制超时，记录为未完成，并在比较不同智能体时保持相同平台设置。

## 等价性的具体定义

用户确认参考传播矢为 `(0,0,0)`，原始参考文件已显式填写。此信息仅在私有侧；题目不提供传播矢答案。参考文件是用户确认的最终精修结果。晶格、晶格角、原子位置与磁矩方向容差在 [协议](protocol.json) 中明确定义以使数值判分可运行。

**磁矩幅值是否参与判定由协议决定，默认不参与。** 现行协议为 v2（`moment_magnitude_in_verdict: false`）：判定只看晶胞、原子位置与元素、磁矩方向与相对排列、磁周期性，即提供者已确认可信的部分；幅值以 `moment_scale_ratio`、`magnitude_within_tolerance`、`max_moment_relative_error` 三个诊断字段输出，不改变 verdict。冻结的 v1 协议保存在 `protocol_v1.json`，把幅值（5% 容差）计回判定，用于复现 v1 的历史结果。**两个版本的成功率不可混算。** 理由见下节：参考幅值未经实验验证，用它做判据会只放过复现占位数字的提交、而判错物理上正确的拟合。

判分器：

1. 使用 PyCifRW 解析 MCIF，用 GSAS-II `cell2AB` 构造晶胞矩阵；不调用联网服务。
2. 把晶轴 μB 分量转换成笛卡尔磁矩，以轴矢量规则 `时间反演 × det(R) × R` 展开磁操作和中心化。
3. 拒绝非有限数、矛盾位点、缺失磁矩、不合法操作和多结构块。
4. 用 spglib 寻找化学平移原胞、Niggli 化简；验证磁矩确实在该原胞上重复。不同晶胞/化学超胞可以表达同一个 k=0 结构，但不能借化学原胞折叠抹掉额外磁周期。
5. 枚举约定容差内的整数原胞基变换，匹配元素及原子位置；对每个**共同的**几何映射比较磁矩方向，允许一次全局反向（`allow_global_time_reversal: false` 时不允许），而不是逐位点任选符号；幅值仅在协议要求时并入判定。

保留核结构对称性的映射同时作用于磁矩，因此包括母相对称等价磁畴；不接受任意旋转磁矩而不旋转结构。磁群编号、原点、原子标签、占位率及热参数均不是独立评分项。

支持一个三维周期相，显式磁操作、晶轴磁矩、常规/原胞/化学超胞表示。支持点号和下划线两种磁字段写法。不支持调制超空间 MCIF、仅有群名无操作、仅有笛卡尔磁矩字段、多个磁相或局部无序模型。对于此 k=0 案例，请将这些输出转换为上述提交格式；限制详见 [题目](task.md)。输入大小与原子数上限是解析保护，不是科学评分。

## 数据说明与版本管理

### 参考磁矩幅值的待验证状态（2026-10-11）

提供者确认参考传播矢和磁空间群可信，但参考磁矩幅值尚需实验验证。

**独立前向拟合的结论（2026-10-11）：参考幅值与实验数据不自洽。** 不经过判分器、直接从参考结构计算核/磁结构因子（b 与 Mn²⁺ ⟨j0⟩ 取自 GSAS-II `atmdata`），与实测低温/高温同反射强度比对照：

- l 偶反射（例如 (100) d=3.575 Å、(002)、(112)）的磁结构因子**严格为零**，5 个 bank 实测比值 1.04–1.25，据此定出两轮测量间的整体标度 k ≈ 1.11；
- 核散射系统消光的纯磁反射 (001) d=6.660 Å 与 (003) d=2.220 Å **低温出现、高温消失**，独立确认 k=0 且磁矩在基面内（若磁矩沿 c 轴，(001) 无磁贡献）；
- 三个最强的含磁反射族给出 |m| ≈ 4.2 μB（k 的四分位范围传播得 3.9–4.6 μB），5 个 bank 独立测同一条 (101) 得 3.0–4.7 μB；
- 参考幅值 2.0 μB 要求 (101) 强度比只有 1.62，而 5 个 bank 实测 3.15–3.56，偏差远超标度与本底的不确定度。

因此 v2 协议把幅值移出通过判据、改为诊断输出。这是**前向比值拟合**而非 Rietveld 精修（未拟合峰形、消光、吸收、各向异性温因子、背景模型），给出的是"参考幅值不可信、量级约 4 μB"的判定与量级区间，**不是可用于替换参考的精修值**。

判定口径由协议版本承担，而不是靠改判分器：v1（幅值计入判定、5% 容差）冻结在 `protocol_v1.json`，用于复现历史结果；现行 `protocol.json` 是 v2。两者由同一份代码按 `--protocol` 求值，因此任何一次运行的判据都能从报告里的 `protocol` 字段完整复原。
若提交与参考的差异仅为共同磁矩幅值，应另行核查所有 bank 的观察、
计算及差值谱，核/磁共同标度、磁形状因子、热参数相关性和参数不确定度。
方向、相对排列、周期或原子位置的差异不能归为单纯幅值问题；
较低的总体残差也不能单独证明绝对磁矩可靠。

实验拟合证据支持修订时，保存诊断、原参考及其哈希，创建新版参考和
评分协议，说明修订依据；不能针对某次输出事后放宽 v1 容差来制造 PASS。
此说明仅属于评测端，不向被测智能体提供参考传播矢、磁群或磁矩信息。

- 使用 BS、HA、LA、MA、SE。BM 排除的可复现原因：`BM_2025.instprm` 与 `BS_2025.instprm` 声明了同一套 bank 元数据（`Bank:1.0`、`2-theta:177.0`），无法把 BM 唯一配对到一个独立 bank。（旧说明写的"BM 文件头 177° 与参数 125° 不一致"与随附文件不符：BM 数据头是 177°，其 instprm 也写 177.0，两者一致。）
- 准备工具自动保存输入 SHA-256；结果保存参考、提交哈希和完整协议。更换参考、数据或容差时应升版本，不跨版本混算成功率；评分口径变化同样升版本（`protocol.json` 是现行 v2，`protocol_v1.json` 是冻结的 v1，评测命令用 `--protocol` 选择）。`allow_parent_symmetry_domains` 从未被代码读取，v2 已删除该键：母相对称等价磁畴是"等价"定义的一部分（判据允许任何保持核结构的几何映射），不是可选开关。`allow_global_time_reversal` 现在真正生效。
- 高低温具体温度、数据 TOF 单位尚未由提供者明确确认；题目不虚构这些值。
- 本 benchmark 只有一个材料体系。多次重复或不同智能体运行不构成多个独立材料案例。
- 原始文件仍在上一级目录，准备工具不会删除、改写或迁移它们。
